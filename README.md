# Голосовой приём заявки

Клиент голосом рассказывает, что случилось, как по телефону. Оператор вымышленной сервисной компании «Монтаж» переспрашивает, чего не хватает, карточка заявки заполняется на глазах. Готовая карточка уходит в разбор n8n из соседнего демо ([tavriq/demo-n8n](https://github.com/tavriq/demo-n8n)): категория, срочность и нужен ли человек. Под каждым ответом видно, сколько заняли распознавание, модель и озвучка.

**Статус на 2026-10-08.** Сервис и страница работают, проверены с Android. Замер на 20 синтезированных звонках ещё не сделан, в «Где ошибается» — только то, что видно на пробах ([evals/](evals/)).

## Кто что решает

| Шаг | Кто |
|---|---|
| конец фразы (1,2 с тишины), тишину не отправлять | страница, `AnalyserNode` |
| речь → текст | `openai/gpt-4o-transcribe`, около 1 с |
| скрыть телефоны и почты | код ([app/pii.py](app/pii.py)) |
| текст → поля карточки и короткое «Принято: …» | `gemini/gemini-3.1-flash-lite`, JSON по схеме, 1,1–1,7 с |
| о чём спросить дальше и когда заявка готова | код ([app/dialog.py](app/dialog.py)) по пустым полям |
| озвучка | готовые фразы озвучены один раз и лежат в памяти, живьём — только пересказ (`openai/gpt-4o-mini-tts`) |

Вопросы забрал код после проб: из трёх вопросов yandexgpt-lite выбрала не тот все три раза, Claude Haiku — один раз, но думала 3–7 секунд. Модели оставлен разбор реплики: на двух разговорах и вопросе не по теме (7 реплик) gemini-3.1-flash-lite заполнила карточку верно 7 из 7.

## Где ошибается

- «Бюджет тысяч пятнадцать» распознавание записало как «1015».
- На пустой или обрезанной записи распознавание выдумывает текст, на шуме — фразы на других языках («Hej.», японское «спасибо»). Сервер не считает репликой текст без кириллицы, эхо подсказки и типовые выдумки ([app/gateway.py](app/gateway.py), `is_noise`).
- Если посреди фразы замолчать дольше секунды, запись закончится раньше.
- Телефон, продиктованный голосом, распознавание пишет цифрами, и код его скрывает. Телефон словами в текстовом поле код не узнает.
- Озвучка пересказа занимает 1,3–2,3 с. Если пересказ не готов за 1,5 с, страница его пропускает, он остаётся текстом.
- Realtime в шлюзе нет: разговор идёт репликами, не потоком.

## Как попробовать

```bash
docker compose up -d --build                      # порт 127.0.0.1:18104
curl -s 127.0.0.1:18104/api/voice/health
id=$(curl -s -X POST 127.0.0.1:18104/api/voice/conversations | python3 -c 'import json,sys; print(json.load(sys.stdin)["id"])')
curl -s -X POST 127.0.0.1:18104/api/voice/conversations/$id/turn -H 'Content-Type: application/json' \
     -d '{"text": "Потёк кондиционер в офисе, Казань, до пятницы"}'
```

Ключ и адрес шлюза Timeweb AI — переменные `LLM_API_KEY` и `LLM_BASE_URL` (в compose — файл `../llm.env`). Разбор n8n — `N8N_TRIAGE_URL`. Контракт API — [docs/api.md](docs/api.md).

Тесты: `pip install -r requirements-dev.txt && pytest`.

## Лимиты и данные

- 5 разговоров в час с адреса (адрес хэшируется с солью), до 6 реплик, запись до 400 КБ.
- Дневной бюджет 15 ₽: худший случай реплики резервируется до вызова, после — списывается факт ([app/pricing.py](app/pricing.py)). Реплика голосом стоит 22–30 копеек.
- Запись голоса не пишется на диск. Текст со скрытыми контактами хранится 30 суток.

## Структура

```

app/dialog.py    разговор: фразы, схема ответа модели, следующий вопрос
app/gateway.py   шлюз: chat, transcribe, speak; фильтр шума
app/pii.py       маскирование контактов
app/n8n.py       передача карточки в разбор n8n
app/store.py     SQLite: разговоры, расход, лимиты
scripts/         пробы моделей и задержки
evals/           результаты проб 08.10
```
